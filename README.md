# 🍔 Fast Food Website Page

Hey there I'm Airah Waseem! 👋  
This is a fun little project I created — a stylish and modern **fast food website homepage** using just **HTML and CSS**. It’s clean, simple, and perfect for anyone looking to build a fast food or restaurant landing page.

---

## 🚀 What This Project Is About

The goal was to design a visually appealing and responsive homepage that gives off **fast food vibes** — think burgers, fries, bold colors, and catchy layout. Whether you're a beginner learning web design or someone creating a portfolio piece, this can be a great start!
